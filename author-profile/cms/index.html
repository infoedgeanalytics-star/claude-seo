How Authors Work

Each author has their own name, bio, title, avatar, social links, expertise tags, and hero stats. The author marked Active is the one displayed on the profile page.

Use Set Active to switch which author the page shows, then click Save Changes in the top bar to persist. Open Author Profile in the sidebar to fine-edit the active author's full details, stats, and more.

Usage Guide

After uploading, click Copy URL on any image to get its data URL, then paste it into the Author Profile → Or paste image URL field to use it as your avatar, or into article/publication thumbnail URLs.

Images are stored in localStorage so they persist between page reloads — no server required.

Bulk Export
Download every author page as individual HTML files in one click. Each file is named author-[firstname-lastname].html.
Integration Guide

1. Download the author's HTML file using the button above.

2. Add your header/footer — the file contains two clearly marked HTML comment blocks:
<!-- PASTE YOUR SITE HEADER HERE -->
<!-- PASTE YOUR SITE FOOTER HERE -->

3. Upload the file to your server, or paste the HTML into your CMS page editor (WordPress → Custom HTML block, Webflow → Embed, etc.).

4. Re-download any time you update content in the CMS — the file always reflects the latest saved data.
